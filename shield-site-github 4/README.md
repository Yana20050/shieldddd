# SHIELD — сайт охоронної компанії

Статичний сайт (HTML/CSS/JS), без збірки та бекенду.

## Запуск локально
```bash
python3 -m http.server 8935
# відкрити http://localhost:8935/
```

## Структура
- `index.html` — розмітка всіх секцій
- `styles.css`, `holo.css`, `hud.css`, `cursor.css`, `perf.css`, `animations.css`, `shiny-button.css` — стилі
- `script.js` — калькулятор AJAX, форми, меню; `animations.js` — GSAP-анімації; `holo-intro.js`, `hud.js`, `cursor.js` — ефекти
- `media/` — фото, відео, зображення обладнання

## Що ще потрібно для продакшну
- Хостинг + домен (HTTPS)
- Обробка форми заявки (зараз не надсилається нікуди)
- Реальні посилання на месенджери (частина `href="#"`)
- Стиснення відео в `media/`
- Версії файлів підключені як `?v=...` — оновлювати вручну при змінах
